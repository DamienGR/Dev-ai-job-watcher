## Sources des données et licences

- **Offres d’emploi** : API « Offres d’emploi » de [France Travail](https://francetravail.io),
  utilisée selon ses conditions d’utilisation. Le site ne publie que des statistiques
  agrégées : aucune annonce, aucun extrait d’annonce, aucune donnée personnelle.
- **Population active par région** : Insee, recensement de la population 2023. Elle sert à
  calculer le nombre d’offres pour 100 000 actifs.
- **Régions et départements** : code officiel géographique de l’Insee.
- **Contours des régions** : IGN, Admin Express, sous Licence ouverte, via le projet
  [france-geojson](https://github.com/gregoiredavid/france-geojson).
- **Fond de carte** : © les contributeurs d’[OpenStreetMap](https://www.openstreetmap.org/copyright),
  données sous licence ODbL, tuiles servies par la fondation OpenStreetMap.

Le code source du site est publié sous licence MIT. Les textes sont rédigés avec Claude, l’IA
